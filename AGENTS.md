# AGENTS.md

These guidelines apply to contributors and AI coding agents working in this
repository.

## Core principles

1. Be consistent with the conventions used throughout the project.
2. Keep code DRY and avoid unnecessary complexity.
3. Prioritize readability and maintainability over premature optimization.
4. Use descriptive, clear names. Avoid single-letter names that resemble
   numbers, such as `l`, `O`, and `I`.
5. Use short names in short scopes and longer names in longer scopes.

## Project scope

`bash-boilerplate.sh` is a reusable Bash boilerplate script. Preserve its
helper catalogue when changing project scaffolding. Make changes to the
script only when the task explicitly calls for them.
